# Changelog

## 2.3.9
Rebuilt in Flutter as an installed Windows program with self-update, and a cleaner look. Opens a
drive or any folder (the start page asks on a new setup); the folder list follows the disk by
itself, so SCAN, REBUILD, FIX NAMES and MISSING are no longer needed. One calm top bar in place of
the banner and toolbar, with a MANUAL (F1) that explains every part, and soft colours. Also several folders, background indexing, UNDO, a preview in LIST / EDIT
with quick tools, right-click menus, drag and drop, Back / Forward, sorting, pins, Properties, a
better FIND, and the standard folders for a new project. See [docs/releases/v2.3.9.md](docs/releases/v2.3.9.md).

## 6.2 and earlier
The HTML application (Project_Folder_Manager.hta, run by mshta.exe):
- 6.2: renamed to Project Folder Manager, no project name built in
- 6.1: VIEW buttons, six pane layouts (Alt+1 to Alt+6), remembered
- 6.0: drives strip (every drive, free space, usage bar), watermark
- 5.3: editable project title, softer banner and highlight colours
- 5.2: ShellExecute file opening, per-row OPEN
- 5.1: self-measuring layout, adaptive banner
- 5.0: clock and calendar, multi-select, copy / cut / paste / delete
