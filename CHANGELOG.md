# Changelog

## 7.0.0
Rebuilt in Flutter as an installed Windows program with self-update. Everything 6.2 did, plus
several projects, background indexing, UNDO, a preview in LIST / EDIT with quick tools, right-click
menus, drag and drop, Back / Forward, sorting, pins, Properties, a better FIND, and the standard
folders for a new project. See [docs/releases/v7.0.0.md](docs/releases/v7.0.0.md).

## 6.2 and earlier
The HTML application (Project_Folder_Manager.hta, run by mshta.exe):
- 6.2: renamed to Project Folder Manager, no project name built in
- 6.1: VIEW buttons, six pane layouts (Alt+1 to Alt+6), remembered
- 6.0: drives strip (every drive, free space, usage bar), watermark
- 5.3: editable project title, softer banner and highlight colours
- 5.2: ShellExecute file opening, per-row OPEN
- 5.1: self-measuring layout, adaptive banner
- 5.0: clock and calendar, multi-select, copy / cut / paste / delete
