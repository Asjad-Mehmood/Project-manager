## Project Folder Manager 7.1.0

**Help and support, built in.**

- The top bar's **More** menu adds **What's new**, **Report a problem** (the contact form opens with
  the program and version filled in), the **error log** and the **open-source licences**, beside
  Manual, Keyboard shortcuts and About.
- **A clear message when something goes wrong.** An unexpected error shows a short notice with
  **Report a problem** and is written to an error log next to the program, to attach when you
  write to us.
- **A start screen** with the icon and name shows the moment you open it.
- The publisher in Windows' list of programs and the status bar now say **exceltokml.com**.

Your folders, disciplines, pins and settings are kept, and everything works as in 7.0.0.

The program updates itself when it opens. New here? Download `ProjectFolderManager-Setup.exe`
below. If Windows says it protected your PC, choose **More info**, then **Run anyway** (the programs are not signed with a paid certificate yet).
