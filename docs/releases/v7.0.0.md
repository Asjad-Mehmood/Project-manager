## Project Folder Manager 7.0.0

The same dashboard as 6.2, rebuilt as a proper Windows program: it installs, keeps itself up to
date, and never freezes while it works.

**Download `ProjectFolderManager-Setup.exe` below and open it.** No administrator rights are
needed. Your 6.2 settings (root path, title, disciplines, view) are brought in by themselves the
first time it opens; if they aren't found, use ⋯ → *Bring in settings from v6*.

### Everything from 6.2
The numbered modules with their discipline colours, sub-folder counts and on-disk dots; VIEW and
OPEN; the tree and ALWAYS TREE; SCAN, REBUILD, FIX NAMES, MISSING; INDEX for this project, the
whole drive or all drives, with STOP; DEEP search and the discipline filter; the side panel with
copy, cut, paste (replace / keep both / skip, once or for all), rename, delete to the Recycle Bin,
LIST / EDIT; DRIVES with free space; the six views (Alt+1 to Alt+6); the clock and calendar; and
the keys Ctrl+C / X / V / A, Delete, F2 and Esc.

### New
- **Installs and updates itself**: a normal installer, Start menu and desktop shortcuts, listed
  in Settings → Apps. New versions are offered when it opens and checked before they install.
- **Several projects**: the clock icon next to ROOT PATH switches between them.
- **Indexes by itself** in the background when a project is new or its index is old, so search is
  instant without pressing INDEX. INDEX and STOP still work as before, and the window stays usable.
- **UNDO (Ctrl+Z)** for renames, moves, copies and new folders.
- **LIST / EDIT shows a preview** of every rename, and any problem, before a name changes; quick
  tools number, add text, find and replace, and change case for every line at once; names can swap.
- **Right-click menus** everywhere, **drag and drop** from the panel onto any folder, **Back /
  Forward**, a clickable path, sorting by name, type, size or date, dates in the panel, the arrow
  keys, Enter, Backspace, F5 and Ctrl+F.
- **PINNED** folders for quick access, **Properties** with a folder's size, and **FIND** that looks
  on every drive for folders holding numbered modules.
- An empty project can be given the standard 00_Admin … 99_Archive folders in one click, and FIX
  NAMES can make the folders of missing modules.
- Folders are merged (as in Explorer) when you replace one with another of the same name.
- Settings and the index are kept in your AppData, so the program works from any folder.
