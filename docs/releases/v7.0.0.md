## Project Folder Manager 7.0.0

The 6.2 dashboard rebuilt as a proper Windows program, with a cleaner look: it installs, keeps
itself up to date, and never freezes while it works.

**Download `ProjectFolderManager-Setup.exe` below and open it.** No administrator rights are
needed. The first time it opens it asks what to open: click a drive, or choose any folder. If a 6.2
copy's settings are on the PC, the start page offers to bring them in.

### Help built in
- **MANUAL** in the top bar (or F1) explains every part of the program, topic by topic: getting
  started, the folder list, search, the index, the side panel, LIST / EDIT, views, the keyboard
  and updates. The start page has HOW TO USE IT too.

### Simpler
- **Open a drive or any folder.** The start page shows your drives with their free space; one
  click opens one. Change the folder any time from the top left, where your recent ones are kept.
- **The list follows the disk by itself.** Folders made, renamed or deleted in Explorer show up
  within a few seconds, so there is nothing to scan, rebuild or fix: SCAN, REBUILD, FIX NAMES and
  MISSING are gone. Disciplines you choose are remembered by folder name.
- **One calm top bar** in place of the banner and the toolbar: the folder, search with DEEP and the
  discipline, then INDEX, GO TO, the view and ⋯, and a small clock (click it for the calendar).
- Above the list: how many folders, the index, EXPAND ALL, COLLAPSE and refresh.

### Everything else from 6.2
The disciplines and their colours, sub-folder counts, VIEW and OPEN, the tree; INDEX for this
folder, the whole drive or all drives, with STOP; DEEP search and the discipline filter; the side
panel with copy, cut, paste (replace / keep both / skip, once or for all), rename, delete to the
Recycle Bin, LIST / EDIT; the drives strip; the six views (Alt+1 to Alt+6); the clock and calendar;
and the keys Ctrl+C / X / V / A, Delete, F2 and Esc.

### New
- **Installs and updates itself**: a normal installer, Start menu and desktop shortcuts, listed
  in Settings → Apps. New versions are offered when it opens and checked before they install.
- **Indexes by itself** in the background when a folder is new or its index is old, so search is
  instant without pressing INDEX. The window stays usable, and STOP keeps what was found.
- **UNDO (Ctrl+Z)** for renames, moves, copies and new folders.
- **LIST / EDIT shows a preview** of every rename, and any problem, before a name changes; quick
  tools number, add text, find and replace, and change case for every line at once; names can swap.
- **Right-click menus** everywhere, **drag and drop** from the panel onto any folder, **Back /
  Forward**, a clickable path, sorting by name, type, size or date, dates in the panel, the arrow
  keys, Enter, Backspace, F5 and Ctrl+F.
- **Pinned** folders, **Properties** with a folder's size, and **FIND** that looks on every drive
  for project folders.
- An empty folder can be given the standard 00_Admin … 99_Archive folders in one click.
- Folders are merged (as in Explorer) when you replace one with another of the same name.
- Settings and the index are kept in your AppData, so the program works from any folder.
